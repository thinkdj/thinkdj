_Otta (ഒറ്റ)_ is Malayalam for "one". One person, one framework, one runtime, _for many_.

That's the whole bet, and everything below is me building it in public.

### ⚡ Ottabase

[![Ottabase: your co-founder is this monorepo](https://ottabase.com/ottabase.com.dark.png)](https://ottabase.com/)

One open-source "all-included" monorepo with auth, OttaORM, queues, cron, realtime, blog/CMS, RBAC, RLS and UI components, wired together for multi-tenant SaaS on Cloudflare Workers. An idea on Friday, a product on Monday is a reality for the solo-founder with Ottabase. MIT licensed.

**[⚡Star the repo](https://github.com/thinkdj/ottabase)** · [⚡ottabase.com](https://ottabase.com) · [⚡Live demo](https://demo.ottabase.com)
